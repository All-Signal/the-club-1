The repository designates `* @anshruhela07-bit @ZeroGravity004 @Ultron09` across the entire codebase. No Pull Request can bypass codeowner review.

### 2. GitHub Actions CI (`merge-guard.yml`)
- Any direct push event to the `main` branch verifies that `github.actor` matches one of the three triumvirate logins. Unauthorized pushes immediately fail and are flagged.
- Pull request runs verify note integrity, check for malformed wikilinks, and ensure proper metadata frontmatter.

- Dismissal of stale reviews upon new commits.
- Strict restriction of push access to authorized accounts.

2. **Standardization:** Notes must follow templates defined in `Templates/` and incorporate valid Obsidian wikilinks.
3. **The Crucible Check:** PR review conducted by one of the three council members.
4. **Merge Execution:** Merged into `main` exclusively by `@anshruhela07-bit`, `@ZeroGravity004`, or `@Ultron09`.
