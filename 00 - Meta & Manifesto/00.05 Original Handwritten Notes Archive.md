## 📄 Note Page 3: Quant (Cont.) & System / Low-Level Hackers

![Note 3 - Systems and Low-Level Hackers](attachments/handwritten-notes/03-systems-hackers.jpeg)

### Verbatim Transcription:
```
b) Point-out real-world inefficiencies :-
   Reach out, talk about a specific trade -> Smart contract.
   Arbitrage opportunity where optimization could increase profits
   or reduce execution time.

c) Share tools :-
   Open-source utilities, backtesting tools, or data pipelines
   immediately build credibility.

(3) System and Low-Level Hackers
Q) Who are they?
-> Engineers who build the foundation of computing, working close to hardware,
   dealing with network kernels, security protocols and massive distributed systems.

Q) Where to find them?
-> Hacker News, trending pages on Github for languages like C, C++ and Rust,

Q) How to reach them?
-> a) Show, don't tell :-
```
