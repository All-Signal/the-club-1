# ⚔️ OPERATIONS // PROOF OF WORK GAUNTLET

All-Signal maintains a strict sub-1% acceptance rate. We do not recruit; we filter through verifiable proof of work.

---

## The Three Vetting Stages

### Stage 1: The Artifact Audit
Candidates must submit one verifiable artifact demonstrating sovereign competence:
- A merged pull request to a top-tier open-source systems/AI repository.
- A live on-chain smart contract, automated trading bot, or verified PnL execution log.
- A production benchmark showing sub-millisecond execution or novel model quantization.
- A published research preprint or 5,000+ word technical breakdown dissecting an obscure systems problem.

### Stage 2: The Code Review & Stress Test
An automated scan and asynchronous code review conducted by **The Triumvirate** ([[00.02 Governance - The Triumvirate]]):
- Checking for copy-pasted boilerplate, hallucinated solutions, and lack of mechanical sympathy.
- Stress-testing edge cases: memory limits, concurrency deadlocks, and network failures.

### Stage 3: [[The 30-Minute Crucible]]
A live, unsweetened technical interrogation with Council members. No slides. Live architecture and raw code only.
